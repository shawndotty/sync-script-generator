# 同步关系可视化 - 实现计划

## 目标与范围
- 在 Sync/FETCH 生成器中，根据当前已配置的同步规则，自动生成一张“Obsidian 文件夹 ↔ 在线数据库表/集合”的关系图，帮助用户更直观理解配置。
- 初版聚焦展示“文件夹 ↔ 表（或集合）”的一对一/多对一关系与方向（Sync/FETCH），不扫描实际文件内容；不展示字段级映射（留作后续扩展）。
- 渲染方案采用 Obsidian 内置的 mermaid 支持：生成 ` ```mermaid ` 文本并通过 MarkdownRenderer 渲染到 Modal。无需引入第三方图可视化库。

## 设计原则与约束
- 安全：仅生成并渲染本地 mermaid 文本，不执行任何远程代码或加载外部资源。
- 最小侵入：不改变现有脚本生成逻辑；新增“关系建模器（RelationshipModel）”从当前表单状态计算关系。
- 即时可视：在 Sync/FETCH 两个 View 的操作区新增“查看关系图”按钮，点击打开 Modal 实时渲染。
- 可导出：在 Modal 提供“复制 mermaid”“导出为 Markdown 笔记”能力，复用现有写入 Vault 模式。

## 数据建模（RelationshipModel）
输出结构（后续以 TS 定义）：
- Node
  - type: "folder" | "remote"
  - id: 稳定唯一值（如 `folder:{path}` / `remote:{platform}:{table}`）
  - label: 展示名（文件夹用相对路径；远端用表/集合名）
- Edge
  - from: folderNodeId
  - to: remoteNodeId
  - direction: "sync" | "fetch"
  - platform: "IOTO" | "obSyncWithMDB"
- Graph
  - nodes: Node[]
  - edges: Edge[]

关系计算要点：
- 读取当前 View 的表单状态（而非模板文本），按 Root/Vault/Folder 三层合并得到“有效规则”。
- 每条有效规则产出一条 Edge；同一 folder 多条规则可对应多个 Edge（多对一/一对多）。
- 平台来源：Sync 使用 `settings.syncPlatform`；Fetch 固定记为 "fetch" 方向并标注平台（若有）。
- 去重策略：相同 from/to/direction 平台重复边合并。

## mermaid 生成规范
- 使用 flowchart LR 布局。
- 使用 subgraph 分区：
  - “Obsidian Vault” 分组放置所有 folder 节点（label 使用相对路径；根用 “/”）。
  - “Remote DB” 分组放置所有远端表/集合节点（label 使用平台前缀可选，如 “IOTO: Tasks”）。
- 边样式：
  - Sync: `folder --> remote`，边上标签 "sync"
  - Fetch: `remote --> folder`，边上标签 "fetch"
- 可选样式（首版简单实现，不做 theme 自定义）

   - 从当前表单状态调用建模 → 生成 mermaid → 打开 Modal

## 边界与后续扩展
- 后续可选：字段级映射展示、图主题切换、按平台分色、支持筛选/高亮子图。

## 假设与兼容性
- Obsidian 版本具备内置 mermaid 支持（当前稳定版已支持）。
- 现有表单状态可完整表达脚本输出所需映射；无需解析脚本文本反推。

## 验收标准
- 在 Sync 和 Fetch 两个视图均可一键打开关系图 Modal，图清晰展示 folder 与远端表的连线与方向。
- 可将 mermaid 文本复制到剪贴板，或导出到 Vault 中的 Markdown 文件，重新打开能正确渲染。
